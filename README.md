# Playstead

Playstead is a workspace for making games with coding agents, running on your own computer. Describe an idea, try it, discuss what happened and decide what deserves more work.

**Status: starting over.** Playstead is being rebuilt with a carefully decided design. There is no application to run yet. The first version is archived at [softhatgames/playstead-v0](https://github.com/softhatgames/playstead-v0).

Playstead's work with coding agents follows [T3 Code](https://github.com/pingdotgg/t3code): its providers, terms and how it runs them. Playstead adds what making a game needs.

- [Product design](docs/PRODUCT.md): the intended experience.
- [Game harness contract](docs/HARNESS.md): how Playstead connects to a running game.
- [Research](docs/research/README.md): what the first version learned.
- [AGENTS.md](AGENTS.md): instructions for coding agents working on Playstead.

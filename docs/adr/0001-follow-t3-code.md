# Follow T3 Code

v0 followed [T3 Code](https://github.com/pingdotgg/t3code) piece by piece: Effect in the host ([0011](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0011-effect-in-the-host.md)), its adapter mechanics under Playstead's own rules ([0012](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0012-t3-code-adapter-mechanics.md)) and its web stack ([0016](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0016-t3-code-web-stack.md)). Each piece was argued on its own, and the rules kept beside T3 Code's had to be reconciled with it decision by decision.

Playstead now follows T3 Code as a whole, as [docs/t3-code.md](../t3-code.md) says; that document holds the rules, the areas followed and the weekly review. Playstead adopts T3 Code's stack whole: TypeScript, Effect, Vite+ and whatever else is needed to work as T3 Code does. Then an idea studied in T3 Code can be written in Playstead with the same tools, and the weekly review's findings apply without translation. Playstead ships as a desktop app that starts its own server, following T3 Code's `apps/desktop`.

**Origin.** This replaces v0's [0001](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0001-typescript-workspace-and-development-host.md), [0010](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0010-host-conversation-record.md), [0011](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0011-effect-in-the-host.md) and [0016](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0016-t3-code-web-stack.md). 0016's port of T3 Code's components under its MIT licence is not repeated. v0's provider ADRs are ignored, because T3 Code is followed instead: [0008](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0008-codex-sign-in-for-milestone-1.md), [0009](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0009-playstead-owned-codex-home.md), [0012](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0012-t3-code-adapter-mechanics.md), [0013](https://github.com/softhatgames/playstead-v0/blob/v0/docs/adr/0013-installed-provider-versions.md), and [0023](https://github.com/softhatgames/playstead-v0/blob/b714e3e001b104a711762c5949537c5921398f8a/docs/adr/0023-playstead-owned-claude-configuration.md)–[0025](https://github.com/softhatgames/playstead-v0/blob/b714e3e001b104a711762c5949537c5921398f8a/docs/adr/0025-installed-signed-in-providers.md) on `v0/claude-provider-decisions`. v0's other ADRs wait for the game features.

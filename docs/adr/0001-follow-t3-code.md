# Follow T3 Code

Playstead follows [T3 Code](https://github.com/pingdotgg/t3code) as a whole, as [docs/t3-code.md](../t3-code.md) says; that document holds the rules, the areas followed and the weekly review. Following it piece by piece, arguing each part on its own and reconciling Playstead's own rules with T3 Code's decision by decision, costs more than it gains and falls behind T3 Code's changes.

Playstead adopts T3 Code's stack whole: TypeScript, Effect, Vite+ and whatever else is needed to work as T3 Code does. Then an idea studied in T3 Code can be written in Playstead with the same tools, and the weekly review's findings apply without translation. Playstead ships as a desktop app that starts its own server, following T3 Code's `apps/desktop`. T3 Code's components are studied and rewritten, never ported.
